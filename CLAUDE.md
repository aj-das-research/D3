# D3: reproduction of "Disagreement, Diversity, and Difficulty in Heterogeneous Multi-Agent LMs" (EACL 2027 Findings)

- Code: fork of `git@github.com:EbadShabbir/D3_EACL.git` (remote `upstream`, push disabled), pushed to
  `git@github.com:aj-das-research/D3.git` (remote `origin`). History was rewritten once with `git filter-repo` to
  redact a leaked Groq API key, so upstream commits must be merged/cherry-picked, not fast-forwarded.
- Paper: `overleaf/` is a git clone of Overleaf project 6a70b566495f23381e394f0a (gitignored here; push it separately).
- Always `source env.sh`. GPUs: **use only GPUs 0 and 1** (set in env.sh).
- Goal: reproduce every table and figure at the paper's numbers or better. Method changes are allowed but must be
  recorded as deviations in the tracker. Never type a number into the tracker that a run did not produce.
- Tracker: `repro/tracker.xlsx` is generated by `repro/build_tracker.py` from `repro/targets.csv` (paper values) and
  `repro/results.csv` (one row per measured value, with the producing command and output path). Rebuild after every run.
